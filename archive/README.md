# Archive

This directory contains obsolete learning exercises retained for historical
reference.

The files are unsupported, may not work, and do not represent current best
practices. They are preserved to show earlier experimentation and development
progress rather than for operational use.

## Contents

- `DirEnum.ps1` and `DirEnum.bat` recursively enumerate directories and
  summarize their contents. Modern PowerShell can provide this functionality
  more directly with `Get-ChildItem`.
- `mkdirls1(Currently doesn't work).bat` and
  `mkdirls2(currently doesn't work).bat` are incomplete, non-working batch
  experiments.

Do not rely on these scripts for production or administrative workflows.
